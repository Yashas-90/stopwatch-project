# Stopwatch-project
Stopwatch using HTML, CSS, JavaScript

## 📌 Project Overview
This project is a simple and interactive stopwatch web application developed using HTML, CSS, and JavaScript.  
It allows users to measure elapsed time accurately with basic control functions.

The project was created as part of a practical assignment to understand frontend web development concepts and tool usage.

---

## 🛠️ Technologies Used
- **HTML** – Structure of the web page  
- **CSS** – Styling and layout design  
- **JavaScript** – Stopwatch logic and time control  

---

## ⚙️ Features
- Start the stopwatch  
- Stop (pause) the stopwatch  
- Reset the stopwatch to zero  
- Real-time time display (minutes, seconds, milliseconds)  
- Clean and responsive user interface  

---

## 📂 Project Structure
stopwatch-project/
├── index.html
├── style.css
└── script.js


---

## ▶️ How to Run the Project
1. Download or clone the repository
2. Open the project folder
3. Open `index.html` in any modern web browser
4. Click **Start**, **Stop**, or **Reset** to control the stopwatch
